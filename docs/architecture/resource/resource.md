# 资源层

资源层主要负责游戏基础素材的管理

## 资源索引

资源索引用于索引资源单元，同时指明一些资源内不支持存储的属性信息。一般存储在一个 JSON 文件中。每个
资源的 key 需要为：`"资源类型.资源UUID"`。其中需要有值：

---

### key

资源的 key，用于在程序中索引对应的资源。

---

### properties

资源的属性，为一个结构体。不同资源的不同格式都有不同的属性信息。

---

### path

资源索引对应的资源路径。路径需要是相对于资源目录的路径

---

如果资源索引中出现不认识的属性，则会自动忽视该属性。

## 游戏资源单元（Resource Unit）

游戏资源是构成游戏元素的基础素材。一个资源单元应当被存储在一个单独的文件中，并由资源索引文件对资源位置
进行索引，并且标注素材文件中的属性。

部分资源属性可能会在图像文件中进行标注，例如一个图像的长/宽和通道数量，如果使用 PNG 格式储存，格式中会
储存这部分信息。这个时候就不需要在索引中进行标注。部分原格式中无法存储的信息（比如图像色彩空间）则需要
在资源索引文件中指明。

白鸟引擎中，游戏资源单元分为以下几种：

- [RUAudio 音频资源单元](./ru_audio.md)

- [RUBinary 二进制资源单元](./ru_binary.md)

- [RUFont 文本资源单元](./ru_font.md)

- [RUImage 图像资源单元](./ru_image.md)

- [RUText 文本资源单元](./ru_text.md)

- [RUVideo 视频资源单元](./ru_text.md)
